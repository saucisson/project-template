# feat: probe-merge, the per-commit greenness dry run (ADR-0008 N5/H5)

- Date: 2026-11-25
- Type: feature (driver tooling, Python) plus one protocol alignment in the merge driver
- Scope: scripts/probe.py (new), scripts/tests/test_probe.py (new), scripts/__main__.py (dispatch), Makefile (probe-merge target), scripts/merge.py (linear-method preference flipped to rebase-first per I3)
- Motive: H5 makes per-commit greenness a driver gate and N5 places it in `make probe-merge`; this implements the local dry run - replay the branch onto a base in a throwaway worktree and require lint, typecheck and imports green on every replayed commit; merge-pr now prefers the rebase linear method since I3 requires nothing to be squashed or rewritten at merge time
- Evidence: the probe domain verified locally - eight behavioral checks (rev-list parsing, dirty-tree and unresolvable-ref refusals, green and red single-commit probes, red-commit probe verdict, empty-range refusal) run against the assembled scripts package; the local run diverged from the pushed files only in the import region (Python 3.12 eager annotations against the house TYPE_CHECKING pattern for 3.15); ruff, mypy, import-linter and make check never ran locally - CI on the PR head is the mechanical gate, and it drove the loop: three ruff findings (one invalid string literal introduced by remote transcription, PLW0108 lambda-to-def, TC004 runtime pytest import) were fixed in-branch; the ruff format diff could not be computed locally, so a temporary branch-only CI helper job ran `ruff format .` inside the locked environment and pushed the result back - the format was computed and applied by ruff itself, never by hand; the helper and an earlier annotations diagnostic branch-only change to ci.yml were both reverted before merge, and ci.yml on this branch is byte-identical to main's again
- Known limits: the fast fronts are the template's three (lint, typecheck, imports); an instance with other fronts extends FAST_FRONT_COMMANDS; pytest stays a head-tier gate, not per-commit - the coverage floor makes intermediate-commit coverage meaningless
